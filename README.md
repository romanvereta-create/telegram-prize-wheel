# Telegram Prize Wheel — инструкция

## Что это
Синхронное визуальное колесо для вашей обычной Telegram-группы.

- Все шестеро открывают одну и ту же ссылку из общего чата.
- Telegram передаёт одинаковый `chat_instance` для этого чата.
- Сервер объединяет всех в одну комнату.
- Только преподаватель с PIN может нажать «Запустить выбор».
- У всех открытых Mini App одновременно запускается одна и та же анимация и появляется один победитель.
- Победитель автоматически выходит из следующих уровней.
- Когда остаются двое, последний запуск распределяет бонус A и бонус B.

ВАЖНО: колесо видно не как анимацию прямо в ленте сообщений. Каждый участник должен открыть Mini App по ссылке в Telegram. Пока приложение открыто, все видят общий запуск.

## 1. Создать Telegram-бота
Открой @BotFather и выполни `/newbot`. Сохрани токен.

## 2. Разместить проект на HTTPS
Самый простой путь — GitHub + Render.

На Render создай Web Service/Blueprint из этого проекта и задай переменные:
- `BOT_TOKEN` — токен от BotFather
- `ADMIN_PIN` — твой секретный PIN
- `BOT_USERNAME` — username бота без @
- `DEMO_MODE=false`

После развёртывания получишь HTTPS-адрес приложения.

## 3. Подключить Mini App в BotFather
`/mybots` → выбрать бота → Bot Settings → Configure Mini App → Enable Mini App.
Указать HTTPS-адрес приложения.

## 4. Ссылка для общей группы
После настройки Main Mini App отправь в вашу обычную группу:

`https://t.me/USERNAME_БОТА?startapp=draw`

Все нажимают её ИМЕННО из этой группы.

## 5. Как провести
1. Все открывают ссылку.
2. Ты тоже открываешь её из группы.
3. Вводишь PIN преподавателя.
4. Вводишь итоговые звёзды всех шестерых.
5. Нажимаешь «Сохранить».
6. Нажимаешь «Запустить выбор».
7. У всех одновременно вращается одно и то же колесо.

## Локальный тест
Если хочешь проверить на ПК до Telegram, на сервере временно задай `DEMO_MODE=true`, затем:

`npm install`
`npm start`

и открой в двух вкладках:
`http://localhost:3000/?room=test`

Обе вкладки увидят один общий запуск.

## Текущая версия
Состояние хранится в памяти сервера. Если сервер перезапустится, звёзды и результаты текущего месяца сбросятся. Для ежемесячного использования это можно позже заменить на постоянное хранение.


## Право хода

В этой версии колесо нельзя запустить «не тому» участнику.

- Все открывают Mini App из общего Telegram-чата.
- В админ-панели преподаватель видит подключившиеся Telegram-аккаунты.
- Перед каждым этапом преподаватель нажимает имя того, кому передаёт ход.
- Кнопка «Крутить колесо» становится активной только у выбранного Telegram-аккаунта.
- У остальных кнопка заблокирована, а сервер отдельно проверяет право хода.
- После запуска право хода автоматически снимается.
- На следующий этап преподаватель назначает нового участника.
- Преподаватель с ADMIN_PIN может запустить колесо сам в любой момент.


## Шансы без базовых +7

В этой версии базовых билетов нет вообще.

- 1 звезда = 1 шанс.
- 18 звёзд → вес 18.
- 7 звёзд → вес 7.
- 0 звёзд → вес 0, пока среди оставшихся есть участники со звёздами.
- Если на каком-то этапе у всех оставшихся 0 звёзд, приложение автоматически делает
  между ними равные сектора, чтобы розыгрыш можно было завершить.
