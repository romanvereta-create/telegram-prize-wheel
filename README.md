# Telegram Prize Wheel — личные призы по звёздам

## Основная логика

Каждый ученик крутит только за свой собственный, заранее скрыто назначенный приз.

- Суперприз — ровно один на весь розыгрыш.
- Большой приз — ровно один на весь розыгрыш.
- Средний приз, Малый приз, Финальный бонус А и Финальный бонус Б могут повторяться.
- Суперприз и Большой приз распределяются по весам `звёзды − минимум + 5` с пересчётом после назначения Суперприза.
- Для остальных четырёх учеников звёзды также влияют на распределение: больше звёзд смещает вероятность к Среднему и Малому призу.
- Всё распределение фиксируется на сервере до первого настоящего вращения.
- До остановки колеса назначенный конкретному ученику приз в интерфейсе не показывается.

## Гость и проверка синхронизации

На экране «Кто ты?» теперь есть отдельная кнопка **👀 Гость**.

Гость:
- не занимает имя ученика;
- не получает право крутить;
- видит общую очередь, вращение колеса и открытые результаты в реальном времени.

У преподавателя в блоке «Привязки Telegram» отображается число гостей онлайн.

В блоке «Сервис» есть кнопка **🎡 Демо-вращение для зрителей**. Она синхронно запускает колесо у всех подключённых к этой Telegram-группе пользователей, включая гостей. Демо-вращение не меняет скрытое распределение, историю и ничей приз.

## Как проверить с двух устройств

1. Открой Mini App из одной и той же Telegram-группы на двух устройствах/аккаунтах.
2. На одном войди как преподаватель по `ADMIN_PIN`.
3. На втором выбери **👀 Гость**.
4. У преподавателя должно появиться `Гостей онлайн: 1`.
5. Нажми **🎡 Демо-вращение для зрителей**.
6. Колесо должно одновременно вращаться у преподавателя и гостя.

## Обычный розыгрыш

1. Ученики открывают Mini App из общей Telegram-группы и выбирают свои имена.
2. Преподаватель входит по `ADMIN_PIN`, вводит звёзды и сохраняет их.
3. Нажимает **«Зафиксировать распределение»**.
4. Очередь идёт автоматически от большего количества звёзд к меньшему.
5. Только текущий ученик получает активную кнопку **«Крутить за свой приз»**.
6. Анимация его вращения транслируется всем открытым экземплярам Mini App в этой группе.
7. После остановки показывается заранее назначенный этому ученику приз, затем очередь автоматически переходит дальше.

## Обновление GitHub / Render

Для обновления существующего репозитория замени `server.js` и `index.html`, а также добавь папку `assets/` из архива. `package.json`, `render.yaml` и переменные окружения можно оставить прежними.

Переменные Render:
- `BOT_TOKEN`
- `ADMIN_PIN`
- `BOT_USERNAME` — можно оставить
- `DEMO_MODE=false`

`server.js` отдаёт `index.html` из корня и папку `/assets` со статическими изображениями.

## Важно

Состояние комнаты хранится в памяти процесса. После перезапуска Render звёзды, скрытое распределение и результаты сбросятся.
