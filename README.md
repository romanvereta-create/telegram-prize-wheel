# Telegram Prize Wheel — личные призы по звёздам

## Что изменено

Теперь ребёнок **крутит только за свой собственный приз**.

Математика распределения:

1. Для Суперприза у каждого ученика вес равен его количеству звёзд.
2. Вероятность получить Суперприз:
   `звёзды ученика / сумма звёзд всей группы`.
3. Обладатель Суперприза исключается из следующего распределения.
4. Для Большого приза веса пересчитываются среди оставшихся по той же формуле.
5. Так продолжается до всех 6 уникальных призов.
6. Если у всех оставшихся участников на каком-то этапе 0 звёзд, между ними используется равный случайный выбор.

Распределение рассчитывается **на сервере и скрывается**. Колесо не определяет приз заново — оно красиво открывает уже рассчитанный личный результат, поэтому ребёнок не может «выиграть приз другому».

## Как проходит месяц

1. Все открывают Mini App из общей Telegram-группы.
2. Каждый ученик один раз выбирает своё имя: София / Вика / Саша / Яромир / Мария / Матвей.
3. Преподаватель входит по `ADMIN_PIN`.
4. Вводит итоговые звёзды.
5. Нажимает **«Сохранить звёзды»**.
6. Проверяет проценты на Суперприз.
7. Нажимает **«Зафиксировать распределение»**.
8. В блоке «Кто крутит сейчас» выбирает ученика. Кнопки отсортированы по звёздам, но порядок уже не влияет на скрытый результат.
9. Только выбранный ученик получает активную кнопку **«Крутить за свой приз»**.
10. У всех открытых Mini App синхронно идёт одна анимация и показывается его личный приз.
11. Повторить для остальных пятерых.

## Обновление существующего GitHub/Render

В текущем репозитории достаточно заменить:
- `server.js`
- `index.html`

`package.json`, `render.yaml` и переменные окружения остаются прежними.

В этой версии `index.html` лежит в корне. `server.js` отдаёт его через `sendFile`, поэтому `express.static('.')` больше не нужен и исходники сервера не публикуются как статические файлы.

Переменные Render:
- `BOT_TOKEN`
- `ADMIN_PIN`
- `BOT_USERNAME` (можно оставить, хотя код его не использует)
- `DEMO_MODE=false`

## Локальный тест

Поставь `DEMO_MODE=true`, затем:

```bash
npm install
npm start
```

Для нескольких «учеников» открой разные адреса, например:

- `http://localhost:3000/?room=test&user=1&name=София`
- `http://localhost:3000/?room=test&user=2&name=Вика`
- `http://localhost:3000/?room=test&user=3&name=Саша`

В каждой вкладке выбери соответствующее имя.

## Важно

Состояние комнаты пока хранится в памяти процесса. После перезапуска Render звёзды, скрытое распределение и результаты сбросятся. Для ежемесячного розыгрыша лучше вводить звёзды непосредственно перед проведением. Позже можно добавить постоянное хранилище.
