# Telegram Prize Wheel — личные призы по звёздам

## Что изменено

Теперь ребёнок **крутит только за свой собственный приз**.

Математика распределения:

1. На каждом этапе берётся минимум звёзд среди оставшихся участников.
2. Вес ученика: `звёзды − минимум + 5`.
3. Вероятность получить текущий приз: `вес ученика / сумма весов оставшихся`.
4. Обладатель текущего приза исключается из следующего распределения.
5. Для следующего приза минимум и все веса пересчитываются среди оставшихся.
6. Так продолжается до всех 6 уникальных призов.
7. Если у всех одинаковое количество звёзд, веса одинаковы (=5), поэтому шансы равные.

Распределение рассчитывается **на сервере и скрывается**. Колесо не определяет приз заново — оно красиво открывает уже рассчитанный личный результат, поэтому ребёнок не может «выиграть приз другому».

## Как проходит месяц

1. Все открывают Mini App из общей Telegram-группы.
2. Каждый ученик один раз выбирает своё имя: София / Вика / Саша / Яромир / Мария / Матвей.
3. Преподаватель входит по `ADMIN_PIN`.
4. Вводит итоговые звёзды.
5. Нажимает **«Сохранить звёзды»**.
6. Проверяет стартовые проценты на Суперприз по формуле `звёзды − минимум + 5`.
7. Нажимает **«Зафиксировать распределение»**.
8. Очередь назначается автоматически: от большего количества звёзд к меньшему.
9. Только текущий ученик получает активную кнопку **«Крутить за свой приз»**.
10. После его вращения приложение само передаёт ход следующему.
11. У всех открытых Mini App синхронно идёт одна анимация и показывается личный приз текущего ученика.

## Обновление существующего GitHub/Render

В текущем репозитории достаточно заменить:
- `server.js`
- `index.html`

`package.json`, `render.yaml` и переменные окружения остаются прежними.

В этой версии `index.html` лежит в корне. `server.js` отдаёт его через `sendFile`, поэтому `express.static('.')` больше не нужен и исходники сервера не публикуются как статические файлы.

Переменные Render:
- `BOT_TOKEN`
- `ADMIN_PIN`
- `BOT_USERNAME` (можно оставить, хотя код его не использует)
- `DEMO_MODE=false`

## Локальный тест

Поставь `DEMO_MODE=true`, затем:

```bash
npm install
npm start
```

Для нескольких «учеников» открой разные адреса, например:

- `http://localhost:3000/?room=test&user=1&name=София`
- `http://localhost:3000/?room=test&user=2&name=Вика`
- `http://localhost:3000/?room=test&user=3&name=Саша`

В каждой вкладке выбери соответствующее имя.

## Важно

Состояние комнаты пока хранится в памяти процесса. После перезапуска Render звёзды, скрытое распределение и результаты сбросятся. Для ежемесячного розыгрыша лучше вводить звёзды непосредственно перед проведением. Позже можно добавить постоянное хранилище.


## Очередь вращений
После фиксации распределения приложение само назначает очередь: от большего количества звёзд к меньшему. После каждого вращения следующий ученик назначается автоматически. При равенстве звёзд используется исходный порядок списка.


## Что добавлено

- Эти картинки автоматически показываются в приложении: текущий уровень, карточка результата и список всех уровней призов.


## Новая логика распределения

- Суперприз — ровно один на весь розыгрыш.
- Большой приз — ровно один на весь розыгрыш.
- Средний приз, Малый приз, Финальный бонус А и Финальный бонус Б могут повторяться.
- Суперприз и Большой приз выбираются скрыто заранее по весам `звёзды − минимум + 5`, с пересчётом после Суперприза.
- Для остальных четырёх учеников результат тоже фиксируется скрыто заранее; больше звёзд смещает вероятность в сторону Среднего и Малого приза.
- До вращения приложение не показывает и не подсвечивает заранее назначенный приз. Эмблема появляется только после остановки колеса.
